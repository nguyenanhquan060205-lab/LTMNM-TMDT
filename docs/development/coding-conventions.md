# Coding Conventions

- Use PHP 8.4 syntax.
- Follow Laravel conventions and Laravel Pint.
- Keep controllers thin.
- Put business rules in Services.
- Use Form Request for validation.
- Use Policy/Middleware for authorization.
- Use enum values for status logic.
- Use Laravel Storage for uploaded files.
- Do not use `guarded = []` in active models.
- Do not write direct DB schema changes outside migrations.
